## 🚀 DÉPLOIEMENT

### ÉTAPES RAPIDES

**1. Préparer les assets (30 min)**
- Créer 9 images OG (1200×630px)
- Créer favicon (512×512px)
- Créer logo haute résolution

**2. Configurer Formspree (15 min)**
- Créer compte sur formspree.io
- Créer formulaire "ZyatrIA - Contact"
- Copier Form ID dans `src/components/Contact.tsx`

**3. Push sur GitHub (10 min)**
```bash
git init
git add .
git commit -m "Initial commit - ZyatrIA Global"
git remote add origin https://github.com/USERNAME/zyatria-website.git
git push -u origin main
```

**4. Déployer sur Cloudflare Pages (20 min)**
- Créer compte sur cloudflare.com
- Connecter repository GitHub
- Configurer build :
  - Framework: Astro
  - Build command: `npm run build`
  - Output directory: `dist`
  - Node version: 18
- Déployer !

**5. Configurer domaine personnalisé (30 min)**
- Acheter domaine (Cloudflare Registrar recommandé)
- Configurer DNS (nameservers Cloudflare)
- Connecter domaine à Pages
- SSL automatique

**6. Tests finaux (15 min)**
- Tester toutes les pages
- Vérifier formulaires
- Tester responsive
- Vérifier SEO (PageSpeed Insights)

**TOTAL : ~2h pour mise en ligne complète**
