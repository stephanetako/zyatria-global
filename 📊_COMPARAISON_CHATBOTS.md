```

3. Message de bienvenue simple
4. Taper un message
5. Recevoir une réponse
6. Continuer la conversation
```

### Nouveau Chatbot

```
1. Clic sur le bouton
2. Fenêtre s'ouvre avec animation
3. Message de bienvenue détaillé
4. Voir les 5 badges de capacités
5. Voir les 4 actions rapides
6. Choisir une action :
   a. Réserver → Calendly
   b. ROI → Calculateur interactif
   c. Démo → Capture email
   d. Question → Conversation
7. Ou parler avec le micro (🎤)
8. Recevoir une réponse intelligente
9. Suggestions contextuelles
10. Continuer l'interaction
```
