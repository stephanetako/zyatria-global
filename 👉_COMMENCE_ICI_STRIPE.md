## 🚀 ÉTAPES RAPIDES

### ÉTAPE 1 : Ouvre Stripe
```
https://dashboard.stripe.com
```
- Connecte-toi
- Assure-toi d'être en **Mode Test**

### ÉTAPE 2 : Va dans Payment Links
1. Menu de gauche → **Produits**
2. Clique sur **Payment Links**
3. Clique sur **+ Nouveau**

### ÉTAPE 3 : Crée ton premier lien
**Utilise les infos du guide pour :**
- Starter - Mensuel : 299 CAD/mois

### ÉTAPE 4 : Copie le lien
- Copie l'URL générée
- Colle-la dans le template

### ÉTAPE 5 : Répète pour les 7 autres
- Suis le guide pour chaque plan
- Coche la case dans le template

### ÉTAPE 6 : Envoie-moi les liens
- Copie le format du template
- Envoie-moi tous les liens
- Je les intègre automatiquement !
