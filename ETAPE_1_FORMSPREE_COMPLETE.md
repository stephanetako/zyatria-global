## 📞 **SUPPORT & TROUBLESHOOTING**

### **Formbutton ne s'affiche pas :**
```bash
# 1. Vérifiez que le script est chargé
# Dans la console (F12) :
# Recherchez : "formspree"

# 2. Vérifiez le Form ID
# Dans FormspreeButton.tsx :
# Form ID doit être : xeelvrdl

# 3. Rafraîchissez la page
Ctrl + F5 (ou Cmd + Shift + R sur Mac)
```

### **Emails non reçus :**
```bash
# 1. Vérifiez les spams Gmail
# 2. Confirmez votre email sur formspree.io
# 3. Attendez 2-3 minutes (délai de livraison)
# 4. Testez avec un autre email
```

### **Erreur lors de l'envoi :**
```bash
# 1. Vérifiez la connexion internet
# 2. Regardez la console (F12)
# 3. Vérifiez que tous les champs obligatoires (*) sont remplis
# 4. Vérifiez le format de l'email
```

### **Dropdowns ne fonctionnent pas :**
```bash
# 1. Cliquez bien sur la flèche ▼
# 2. Scrollez dans la liste si nécessaire
# 3. Sélectionnez une option
# 4. Vérifiez qu'elle apparaît dans le champ
```
