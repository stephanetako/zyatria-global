## 🎯 Processus de Vente Automatique

### 1. Accueil Chaleureux
```
"Bonjour ! 👋 Je suis Zyra, votre assistante IA chez ZyatrIA Global. 
Comment puis-je vous aider aujourd'hui ?"
```

### 2. Qualification du Prospect

Le chatbot pose 3 questions clés :

**Question 1 : Volume**
- "Combien de demandes clients/prospects recevez-vous par jour environ ?"
- Options : 0-10, 10-50, 50-100, 100+

**Question 2 : Budget**
- "Quel est votre budget mensuel pour l'automatisation ?"
- Options : < 100$, 100-300$, 300-500$, 500$+

**Question 3 : Urgence**
- "Quand souhaitez-vous démarrer ?"
- Options : Immédiatement, Cette semaine, Ce mois-ci, Je réfléchis

### 3. Recommandation Intelligente

Selon les réponses :

**→ Starter** si :
- Volume : 0-10 demandes/jour
- Budget : < 300$/mois
- Besoin simple

**→ Professional** si :
- Volume : 10-100 demandes/jour
- Budget : 300-500$/mois
- Besoin d'automatisation avancée

**→ Enterprise** si :
- Volume : 100+ demandes/jour
- Budget : 500$+/mois
- Besoin de solution complète
