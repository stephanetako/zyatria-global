## 🧪 TESTER MAINTENANT

### 1. Démarrer le serveur
```bash
npm run dev
```

### 2. Ouvrir dans le navigateur
```
http://localhost:3000
```

### 3. Tester le chatbot

#### Test 1 : Ouverture
- Cliquez sur le bouton flottant en bas à droite
- Vérifiez que le chatbot s'ouvre avec le message de bienvenue

#### Test 2 : Questions rapides
Cliquez sur les suggestions :
- "Quels sont vos micro-agents?"
- "Combien ça coûte?"
- "Comment ça marche?"

#### Test 3 : Calculateur ROI
1. Cliquez sur "Calculer mon ROI"
2. Entrez le nombre d'employés (ex: 10)
3. Entrez les heures/semaine (ex: 20)
4. Entrez le secteur (ex: E-commerce)
5. Vérifiez le calcul automatique

#### Test 4 : Reconnaissance vocale
1. Cliquez sur l'icône micro 🎤
2. Autorisez l'accès au micro
3. Parlez votre question
4. Vérifiez la transcription

#### Test 5 : Calendly
1. Cliquez sur "Réserver une consultation"
2. Vérifiez que Calendly s'ouvre dans un nouvel onglet

#### Test 6 : Capture d'email
1. Tapez votre email dans le chat
2. Vérifiez la réponse de confirmation

## 🚨 Si vous voyez des problèmes

### Le chatbot ne s'affiche pas
1. Vérifiez la console pour les erreurs
2. Rechargez la page (Ctrl+R)
3. Videz le cache (Ctrl+Shift+R)

### Le micro ne fonctionne pas
1. Vérifiez les permissions du navigateur
2. Utilisez HTTPS ou localhost
3. Testez sur Chrome/Edge (meilleur support)

### L'API Claude ne répond pas
- C'est normal ! Le chatbot a un **fallback intelligent**
- Il utilisera les réponses prédéfinies
- Toutes les fonctionnalités marchent quand même
