## ⚡ DÉMARRAGE RAPIDE

### 1. Obtenir une clé API Claude

https://console.anthropic.com/ → Settings → API Keys → Create Key

### 2. Configurer

```bash
# Linux/Mac
./configure-claude.sh

# Windows
.\configure-claude.ps1
```

### 3. Déployer

```bash
npm run build
git add .
git commit -m "✨ Upgrade to Claude"
git push origin main
```
