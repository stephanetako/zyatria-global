# 🔍 DIAGNOSTIC - Page Blanche

## Problème identifié

La page affiche une page blanche, ce qui indique généralement une erreur JavaScript côté client.

---

## 🛠️ SOLUTION RAPIDE

### Étape 1 : Ouvrir la console du navigateur

1. Appuyez sur **F12** (ou clic droit → Inspecter)
2. Allez dans l'onglet **Console**
3. Regardez s'il y a des erreurs en rouge

### Étape 2 : Vérifier les erreurs communes

Les erreurs possibles :
- ❌ `useForm is not defined`
- ❌ `Cannot read property of undefined`
- ❌ `Module not found`
- ❌ Erreur de CORS
