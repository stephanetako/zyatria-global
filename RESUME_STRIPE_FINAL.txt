ÉTAPE 1 : Créer vos produits Stripe (5 min)
────────────────────────────────────────────
1. Allez sur https://dashboard.stripe.com
2. Activez le Mode Test (toggle bleu)
3. Products → + Add product
4. Créez :
   ├─ Starter Plan : 49€/mois
   └─ Business Plan : 149€/mois


ÉTAPE 2 : Générer les Payment Links (3 min)
────────────────────────────────────────────
1. Pour chaque produit : "Create payment link"
2. Configurez :
   ├─ ☑ Email + Name
   ├─ Redirect to: https://votre-site.com/success
   └─ ☑ Allow promotion codes
3. Copiez les liens


ÉTAPE 3 : Intégrer les liens (1 min)
────────────────────────────────────────────
1. Ouvrez : src/config/stripe-links.ts
2. Remplacez les liens :

   export const STRIPE_TEST_LINKS = {
     starter: {
       eur: 'COLLEZ_VOTRE_LIEN_ICI',
       usd: 'COLLEZ_VOTRE_LIEN_ICI',
       cad: 'COLLEZ_VOTRE_LIEN_ICI',
     },
     business: {
       eur: 'COLLEZ_VOTRE_LIEN_ICI',
       usd: 'COLLEZ_VOTRE_LIEN_ICI',
       cad: 'COLLEZ_VOTRE_LIEN_ICI',
     },
   };

3. Sauvegardez (Ctrl+S)


ÉTAPE 4 : Tester (1 min)
────────────────────────────────────────────
1. Votre site → Section Pricing
2. Clic "Payer maintenant"
3. Carte test : 4242 4242 4242 4242
4. Validez

✅ Redirection vers /success = SUCCESS !
