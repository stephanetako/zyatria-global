## ❌ PROBLÈMES COURANTS

### **Le site ne démarre pas ?**
```bash
# Tuez le processus sur le port 3000
npx kill-port 3000

# Redémarrez
npm run dev
```

### **Les changements ne s'affichent pas ?**
```bash
# Videz le cache du navigateur
Ctrl + Shift + R (Windows)
Cmd + Shift + R (Mac)
```

### **Erreur TypeScript ?**
```bash
# Vérifiez les erreurs
npm run astro check
```
