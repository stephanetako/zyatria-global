## 🔧 CONFIGURATION

### Variables d'environnement nécessaires

```env
# Pour Claude (questions commerciales)
ANTHROPIC_API_KEY=votre_clé_claude

# Pour Mistral (questions techniques)
MISTRAL_API_KEY=votre_clé_mistral
```

### Fallback intelligent

Si une API ne répond pas :
1. Le chatbot essaie l'autre IA
2. Si les deux échouent, affiche un message amical
3. Propose des alternatives (email, téléphone)

**Résultat** : Le chatbot ne plante JAMAIS !
