## 🆘 EN CAS DE PROBLÈME

### Le Site ne S'Affiche Pas ?
```
1. Vérifier les logs : Dashboard → Logs
2. Vérifier le déploiement : Dashboard → Deployments
3. Tester localement : npm run dev
```

### Le Chatbot ne Répond Pas ?
```
1. Vérifier MISTRAL_API_KEY sur Cloudflare
2. Consulter les logs API
3. Vérifier le quota Mistral
```

### Les Paiements ne Fonctionnent Pas ?
```
1. Vérifier les clés Stripe sur Cloudflare
2. Vérifier le mode (test/live)
3. Consulter les logs Stripe
```
