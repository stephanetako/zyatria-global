## 📝 **ÉTAPE PAR ÉTAPE**

### **1. Créer un compte Canva (2 min)**

```
🌐 Allez sur : https://www.canva.com
📧 Inscrivez-vous (gratuit) avec :
   - Email
   - Google
   - ou Facebook
```

---

### **2. Créer un nouveau design (1 min)**

```
1. Cliquez sur "Créer un design" (bouton violet en haut à droite)
2. Tapez "1200 x 630" dans la barre de recherche
3. OU cliquez sur "Taille personnalisée"
4. Entrez : Largeur 1200 | Hauteur 630
5. Cliquez sur "Créer un design"
```

**Vous êtes maintenant dans l'éditeur Canva ! 🎨**

---

### **3. Créer le background dégradé (3 min)**

#### **Option A : Gradient automatique (recommandé)**

```
1. Cliquez sur votre canvas (zone blanche)
2. Dans le menu de gauche, cliquez sur "Couleur de fond"
3. Cliquez sur l'icône "Dégradé" (en haut de la palette)
4. Choisissez un dégradé "Diagonal" ou "Linear"
5. Modifiez les couleurs :
   - Point 1 : #6366F1 (bleu indigo)
   - Point 2 : #8B5CF6 (violet)
   - Point 3 : #C98769 (orange) - ajouter un 3e point si possible
```

#### **Option B : Rectangle avec dégradé manuel**

```
1. Éléments → Formes → Rectangle
2. Redimensionnez pour couvrir tout le canvas (1200x630)
3. Cliquez sur le rectangle → Couleur
4. Choisissez "Dégradé"
5. Ajustez les couleurs comme ci-dessus
```

**Résultat : Un beau dégradé bleu → violet → orange 🌈**

---

### **4. Ajouter le titre principal (3 min)**

```
1. Cliquez sur "Texte" dans le menu gauche
2. Choisissez "Ajouter un titre"
3. Tapez : "ZYATRIA GLOBAL"

Formatage :
- Font : Poppins Bold ou Inter Bold ou Montserrat Bold
- Taille : 96 (ou 100-110)
- Couleur : #FFFFFF (blanc)
- Alignement : Centré
- Position : Centre horizontal, ~150-180px du haut
- Effet : Ajouter une ombre légère (optionnel)
  → Effets → Ombre → Opacité 30%, Flou 20, Distance 5
```

**Astuce Canva :**
- Pour centrer : Sélectionnez le texte → En haut "Position" → Centrer horizontalement

---

### **5. Ajouter le sous-titre (2 min)**

```
1. Texte → Ajouter un sous-titre
2. Tapez : "AI Without Borders"

Formatage :
- Font : Poppins Medium ou Inter Medium
- Taille : 52 (ou 48-56)
- Couleur : #FFFFFF (blanc)
- Opacité : 90-95%
- Alignement : Centré
- Position : Juste sous le titre (espacement 15-20px)
```

---

### **6. Ajouter la description (2 min)**

```
1. Texte → Ajouter un corps de texte
2. Tapez : "Deploy intelligent AI agents in 7-15 days"

Formatage :
- Font : Poppins Regular ou Inter Regular
- Taille : 36 (ou 32-40)
- Couleur : #FFFFFF (blanc)
- Opacité : 85%
- Alignement : Centré
- Position : Sous le sous-titre (espacement 20px)
```

---

### **7. Ajouter le badge Canadian (2 min)**

```
1. Éléments → Formes → Rectangle arrondi
2. Dimensions : ~400px largeur x 50px hauteur
3. Couleur : #373D36 (vert foncé)
4. Opacité : 60%
5. Coins arrondis : Maximum (style "pill")
6. Position : En haut à droite (marge 40px) OU en bas centré

Texte dans le badge :
1. Texte → Corps de texte
2. Tapez : "🇨🇦 Canadian Company | Quebec"
3. Font : Poppins Medium
4. Taille : 24-28
5. Couleur : #FFFFFF
6. Position : Centré sur le rectangle
```

**Astuce :** 
- Sélectionnez le rectangle ET le texte
- Clic droit → Grouper (pour déplacer ensemble)

---

### **8. Ajouter les stats badges (optionnel - 2 min)**

```
Créez 3 petits badges en bas :

Badge 1 :
- Texte : "⭐ 4.9/5"
- Font : Poppins Medium, Taille 22
- Background : Rectangle arrondi blanc (opacité 20%)
- Position : Bas gauche

Badge 2 :
- Texte : "🚀 500+ Agents"
- Même style
- Position : Bas centre

Badge 3 :
- Texte : "🌍 4 Continents"
- Même style
- Position : Bas droite

Espacement : 40px entre chaque badge
Marge bottom : 40-50px
```

---

### **9. Ajouter le logo (optionnel - 1 min)**

```
Option 1 : Utiliser le favicon
1. Télécharger → Votre appareil
2. Sélectionnez public/favicon.svg (le favicon créé plus tôt)
3. Taille : 80x80px
4. Position : Coin haut gauche (marge 40px)

Option 2 : Créer un badge "Z"
1. Texte → "Z"
2. Font : Poppins Black
3. Taille : 72
4. Couleur : #C98769
5. Background : Cercle blanc (opacité 20%)
6. Position : Coin haut gauche
```

---

### **10. Télécharger (1 min)**

```
1. Cliquez sur "Partager" (ou "Share") en haut à droite
2. Cliquez sur "Télécharger"
3. Type de fichier : PNG
4. Qualité : Standard (ou High si vous voulez)
5. Cliquez sur "Télécharger"

Le fichier sera téléchargé dans votre dossier "Downloads"
Nom : "Design sans titre.png" (ou similaire)
```

---

### **11. Renommer et placer dans le projet (1 min)**

```bash
# Dans votre ordinateur :
1. Allez dans "Téléchargements" / "Downloads"
2. Trouvez le fichier PNG téléchargé
3. Renommez-le en : "og-image.png"
4. Copiez-le dans le dossier "public/" de votre projet

# Sur Mac :
mv ~/Downloads/Design\ sans\ titre.png ~/votre-projet/public/og-image.png

# Sur Windows :
# Glissez-déposez le fichier dans public/
```

## 💡 **CONSEILS DE DESIGN**

### **Lisibilité :**
- ✅ Texte blanc sur fond foncé/coloré = Bon contraste
- ✅ Ombres légères sur le texte = Meilleure visibilité
- ✅ Font bold pour le titre = Plus impactant
- ❌ Évitez trop de texte (max 3-4 lignes)
- ❌ Évitez les fonts trop fantaisistes

### **Hiérarchie :**
```
Titre (très grand) : ZyatrIA Global
  ↓
Sous-titre (grand) : AI Without Borders
  ↓
Description (moyen) : Deploy in 7-15 days
  ↓
Badges (petit) : Stats et Canadian Company
```

### **Couleurs :**
- **Fond** : Gradient coloré (bleu → violet → orange)
- **Texte** : Blanc (toujours visible)
- **Accents** : Orange #C98769 pour les highlights
- **Badges** : Semi-transparent (20-60% opacité)

### **Espacement :**
- Marges extérieures : 40-60px
- Entre les éléments : 15-25px
- Centre visuel : Légèrement au-dessus du centre (position dorée)
