## ✅ Étape 2 : Configurer l'Hébergement

### 🚀 Options d'Hébergement pour votre site Astro

#### **Option A: Webflow Hosting** ⭐⭐⭐ (Recommandé - Intégration Native)

**Pourquoi Webflow ?**
- ✅ Intégration parfaite avec Webflow Apps
- ✅ Performance mondiale (CDN Fastly)
- ✅ SSL automatique et gratuit
- ✅ Backups automatiques
- ✅ Support Webflow inclus
- ✅ Facile à gérer depuis votre dashboard Webflow

**Plans Disponibles :**

| Plan | Prix | Idéal Pour | Caractéristiques |
|------|------|------------|------------------|
| **Basic** | ~18$/mois (14$/mois annuel) | Sites vitrine sans CMS | • Domaine personnalisé<br>• SSL gratuit<br>• 100 pages max<br>• Pas de CMS |
| **CMS** | ~29$/mois (23$/mois annuel) | Sites avec blog/actualités | • Domaine personnalisé<br>• SSL gratuit<br>• 2000 items CMS<br>• 100 pages statiques<br>• Blog, études de cas, etc. |
| **Business** | ~49$/mois (42$/mois annuel) | Sites e-commerce/avancés | • Tout du CMS<br>• 10,000 items CMS<br>• Code export<br>• API access |

**✅ Plan Recommandé pour ZyatrIA Global : CMS** (~23$/mois annuel)
- Permet d'ajouter un blog pour partager expertise IA
- Études de cas clients
- Section actualités
- Témoignages dynamiques

**Comment déployer sur Webflow :**

1. **Dans votre Webflow Dashboard**
   ```
   1. Aller dans votre site settings
   2. Cliquer sur "Hosting"
   3. Choisir un plan (Basic ou CMS)
   ```

2. **Connecter votre domaine**
   ```
   1. Dans Hosting → Custom domains
   2. Cliquer "Add custom domain"
   3. Entrer : zyatria.com
   4. Suivre les instructions DNS
   ```

3. **Configuration DNS (Automatique)**
   - Webflow vous donne les enregistrements DNS
   - Copier-coller dans votre registrar (Namecheap, etc.)
   ```
   Enregistrement A :
   - Nom : @
   - Valeur : 75.2.70.75 (exemple)
   
   Enregistrement CNAME :
   - Nom : www
   - Valeur : proxy-ssl.webflow.com
   ```

4. **Publier** ✨
   - Cliquer "Publish to production domain"
   - Votre site est en ligne en quelques minutes !

**💡 Avantages Webflow Hosting :**
- Un seul endroit pour gérer tout (design + hosting)
- Pas besoin de GitHub/déploiement technique
- Interface visuelle simple
- Support client Webflow

### 📝 **Étape 3 : Connecter ton Domaine à Webflow**

#### **Partie A : Dans Webflow Dashboard**

**1. Ouvrir les Paramètres de Hosting**
```
1. Connectez-vous à Webflow (webflow.com)
2. Ouvrez votre projet "ZyatrIA Global"
3. Cliquez sur l'icône "Settings" (engrenage) en haut à droite
4. Dans le menu de gauche, cliquez sur "Hosting"
```

**2. Ajouter votre Domaine Personnalisé**
```
1. Dans la section "Custom domains"
2. Cliquez sur le bouton "+ Add Custom Domain"
3. Une fenêtre s'ouvre
```

**3. Entrer votre Domaine**
```
1. Dans le champ, tapez : zyatria.com
   (ou le domaine que vous avez acheté)

2. NE PAS mettre "www" devant
   ✅ Correct : zyatria.com
   ❌ Incorrect : www.zyatria.com
   
3. Cliquez "Add Domain"
```

**4. Webflow vous Donne les DNS**

Webflow va afficher une page avec les enregistrements DNS à configurer :

```
📋 Enregistrements DNS à Copier :

Pour le domaine racine (@) :
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Type: A
Name: @ (ou laisser vide)
Value: 75.2.70.75
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pour le sous-domaine www :
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Type: CNAME
Name: www
Value: proxy-ssl.webflow.com
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**⚠️ Important :** 
- Laissez cette page **ouverte**
- Nous allons copier ces valeurs dans votre registrar

---

#### **Partie B : Configuration DNS selon votre Registrar**

### 🔹 **Option 1 : Namecheap** (Le plus courant)

**1. Se Connecter à Namecheap**
```
1. Aller sur namecheap.com
2. Cliquer "Sign In"
3. Entrer vos identifiants
```

**2. Accéder à la Gestion DNS**
```
1. Cliquer sur "Domain List" dans le menu
2. Trouver votre domaine (zyatria.com)
3. Cliquer sur "Manage" à droite du domaine
4. Aller dans l'onglet "Advanced DNS"
```

**3. Supprimer les Enregistrements Existants**
```
Dans la section "Host Records", vous verrez :
- Parking Page (A Record)
- URL Redirect Record

➡️ Cliquer sur l'icône "poubelle" 🗑️ pour TOUT supprimer
```

**4. Ajouter l'Enregistrement A**
```
1. Cliquer "+ Add New Record"
2. Sélectionner "A Record"
3. Remplir :
   ┌─────────────────────────────────┐
   │ Type: A Record                  │
   │ Host: @                         │
   │ Value: 75.2.70.75              │
   │ TTL: Automatic                  │
   └─────────────────────────────────┘
4. Cliquer "✓" (coche verte) pour sauvegarder
```

**5. Ajouter l'Enregistrement CNAME**
```
1. Cliquer "+ Add New Record"
2. Sélectionner "CNAME Record"
3. Remplir :
   ┌─────────────────────────────────┐
   │ Type: CNAME Record              │
   │ Host: www                       │
   │ Value: proxy-ssl.webflow.com   │
   │ TTL: Automatic                  │
   └─────────────────────────────────┘
4. Cliquer "✓" (coche verte) pour sauvegarder
```

**6. Résultat Final**

Vous devriez avoir exactement 2 enregistrements :

```
┌────────┬──────┬────────────────────────┬───────────┐
│ Type   │ Host │ Value                  │ TTL       │
├────────┼──────┼────────────────────────┼───────────┤
│ A      │ @    │ 75.2.70.75            │ Automatic │
│ CNAME  │ www  │ proxy-ssl.webflow.com │ Automatic │
└────────┴──────┴────────────────────────┴───────────┘
```

✅ **Configuration Namecheap Terminée !**

#### **Problème 1 : "DNS records not found" après 2 heures**

**Solutions :**
```
1. Vérifier que les DNS sont EXACTEMENT :
   A Record : @ → 75.2.70.75
   CNAME : www → proxy-ssl.webflow.com

   Windows : ipconfig /flushdns
   Mac : sudo killall -HUP mDNSResponder

3. Attendre encore 2-4 heures (propagation lente)

4. Vérifier sur whatsmydns.net
```

#### **Problème 2 : "This site can't be reached"**

**Solutions :**
```
1. Vérifier que le plan Webflow est actif
   Settings → Billing

2. Vérifier que le site est publié
   Cliquer "Publish" dans le Designer

3. Essayer en navigation privée

4. Vider cache navigateur (Ctrl+F5 ou Cmd+Shift+R)
```

```

   Settings → Hosting → SSL Certificate
   Devrait dire "Active"

3. Forcer HTTPS :
   Settings → Hosting → Enable SSL
```

```
   Chrome : Ctrl+Shift+Delete (Windows)
   Chrome : Cmd+Shift+Delete (Mac)

3. Tester en navigation privée
```
