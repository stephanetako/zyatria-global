## 🔑 VARIABLES D'ENVIRONNEMENT

À configurer sur Cloudflare après le premier déploiement:

```
1. MISTRAL_API_KEY          → Chatbot IA
2. STRIPE_PUBLIC_KEY        → Paiements (public)
3. STRIPE_SECRET_KEY        → Paiements (secret)
4. STRIPE_WEBHOOK_SECRET    → Webhooks Stripe
5. FORMSPREE_FORM_ID        → Formulaires
```

**Valeurs:** Voir fichier `.env`
