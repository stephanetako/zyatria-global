## 🚀 SCRIPTS DE DÉPLOIEMENT

### `deploy-live-mode.ps1` (Windows)
Script PowerShell automatique qui :
- ✅ Vérifie le statut Git
- ✅ Build le projet
- ✅ Commit et push vers GitHub
- ✅ Guide pour la configuration Cloudflare
- ✅ Guide pour le webhook Stripe

**Utilisation :**
```powershell
.\deploy-live-mode.ps1
```

### `deploy-live-mode.sh` (Linux/Mac)
Script Bash automatique (même fonctionnalités que le script PowerShell)

**Utilisation :**
```bash
./deploy-live-mode.sh
```

## 🎯 QUEL FICHIER UTILISER ?

### Pour un déploiement rapide (5 minutes)
1. Lisez `⚡_DEPLOYER_MAINTENANT.txt`
2. Lancez `deploy-live-mode.ps1` ou `deploy-live-mode.sh`
3. Suivez les instructions à l'écran

### Pour un déploiement guidé (10 minutes)
1. Lisez `👉_LANCER_DEPLOIEMENT.md`
2. Suivez les étapes une par une
3. Vérifiez avec la checklist

### Pour une configuration détaillée (20 minutes)
1. Lisez `🚀_DEPLOIEMENT_FINAL_LIVE_MODE.md`
2. Suivez toutes les étapes
3. Configurez tous les services
4. Vérifiez avec `✅_PRET_POUR_DEPLOIEMENT.md`

### Pour une documentation complète
1. Consultez `📚_GUIDE_COMPLET_DEPLOIEMENT.md`
2. Utilisez-le comme référence
3. Consultez la section dépannage si nécessaire
