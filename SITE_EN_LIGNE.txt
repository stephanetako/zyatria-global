📋 DIAGNOSTIC
═════════════
Le projet est configuré pour Cloudflare WORKERS, pas Pages.
C'est pourquoi "wrangler pages deploy" ne fonctionne pas.

✅ SOLUTION SIMPLE
═══════════════════

1️⃣ DÉPLOYER AVEC LA BONNE COMMANDE
   
   Ouvrez PowerShell et exécutez:
   
   cd C:\Users\Utilisateur\OneDrive\Bureau\zyatria-global
   npx wrangler deploy dist/server/entry.mjs --name zyatria-global --compatibility-date 2024-01-01

2️⃣ AUTHENTIFICATION (si demandée)
   
   Si Wrangler demande de vous authentifier:
   - Tapez "Y" pour ouvrir le navigateur
   - Connectez-vous à votre compte Cloudflare
   - Autorisez Wrangler

3️⃣ RÉSULTAT
   
   Votre site sera en ligne à:
   https://zyatria-global.VOTRE-SOUS-DOMAINE.workers.dev

📊 DIFFÉRENCE WORKERS vs PAGES
═══════════════════════════════

WORKERS (votre configuration actuelle):
✓ Serveur dynamique avec SSR
✓ Peut gérer des API routes
✓ Plus flexible pour les applications complexes
✓ URL: *.workers.dev

PAGES:
✓ Sites statiques ou SSR
✓ Déploiement depuis Git
✓ URL: *.pages.dev
