📝 Comment Créer les Liens Manquants

  1. Allez sur Stripe Dashboard → Payment Links
  2. Cliquez sur "+ New"
  3. Créez un produit pour chaque micro-agent avec le prix indiqué
  4. Copiez l'URL du Payment Link (commence par https://buy.stripe.com/...)
  5. Remplacez dans src/config/stripe-links.ts :
microAgents: {
  leadQualification: 'VOTRE_LIEN_ICI', // 69 $CA/mois
  customerSupport: 'VOTRE_LIEN_ICI', // 69 $CA/mois
  appointments: 'VOTRE_LIEN_ICI', // 68 $CA/mois
  prospectFollowup: 'VOTRE_LIEN_ICI', // 180 $CA/mois
  realEstate: 'VOTRE_LIEN_ICI', // 208 $CA/mois
  ecommerce: 'VOTRE_LIEN_ICI', // 195 $CA/mois
}
